Which image provides more clinically useful information for diagnosis?

    Instructions

    Once you begin, you’ll view 2 versions of 120 subjects’ tau PET scans. The first version is shown in the top row, and the second is shown in the bottom row. Each version contains four glass-brain views on the same Tau SUVR scale: yellow is low uptake, red to black is high.

    For each subject, choose the row that gives more clinically useful information for diagnosis (where tau is, how far it extends, its pattern), or Equal if neither does.
